# Security Policy

## Supported Versions

The following versions of the SATYAM platform are currently supported for security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The SATYAM development team takes the security of public procurement systems seriously. If you discover a security vulnerability or security defect:

1. **Do not create a public GitHub issue.**
2. Send an email with details and reproduction steps to: `security@satyam-procurement.internal` or contact the repository maintainer directly.
3. Include:
   - Description of the vulnerability and affected endpoint/component
   - Proof-of-concept (PoC) or reproduction steps
   - Potential impact under General Financial Rules (GFR 2017) procurement workflows
4. You will receive an acknowledgment within 48 hours with a triage assessment and remediation timeline.

For the full security audit and verified controls report, please see [docs/security-audit.md](./docs/security-audit.md).
